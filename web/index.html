Pull videos from a link

Pulling from Instagram, Facebook or YouTube needs the builder's local helper running on your Mac. Without it, everything else in the builder still works; you just upload videos yourself.

Start the helper

  1. Open Terminal (Cmd+Space, type Terminal).
  2. Go to the builder's folder and start it:
    cd ~/Documents/GitHub/ctv-social-spot-builder && ./start.sh
  3. The builder opens at http://localhost:8765 with the Pull from a link box. Leave the Terminal window open while you work.

First time? Get the folder from the GitHub repo (Code › Download ZIP, or clone it). The first start takes about a minute to set up.

If a pull is blocked

  • Needs a login: it uses your Safari login automatically, so log in to Instagram or Facebook in Safari first.
  • "macOS is blocking it": System Settings › Privacy & Security › Full Disk Access, turn on Terminal, then quit Terminal and run ./start.sh again.
  • Private post: only works if your Safari login can see it.
  • Rate-limited: wait a few minutes and try again, or save the video from the post yourself and upload it.

Only use videos you own or have permission to use.
